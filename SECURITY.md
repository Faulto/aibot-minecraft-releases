# Security

Do not open a public issue containing a credential, Microsoft device code, account cache, private
server address, exploit detail, or unredacted runtime evidence. Report suspected vulnerabilities
privately to the repository owner through GitHub's private vulnerability reporting channel when it
is available, or through an already established private contact.

Release descriptors are intentionally public. Treat a changed repository identity, mutable image
tag, missing digest, non-public GHCR image, unexpected platform, protocol/contract mismatch, or
checksum failure as a release-integrity incident.
